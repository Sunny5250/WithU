# macOS 首次打开 WithU

适用于 GitHub v2.0.0 的 Apple Silicon 安装包。**当前版本尚未经过 Apple 公证**，首次打开时可能被 macOS 拦截。是否批准运行，请由你在确认来源和文件完整性后决定。

## 先核对下载来源与文件

从 [WithU 官方 GitHub 发布页](https://github.com/Sunny5250/WithU/releases/tag/v2.0.0)下载 `WithU-2.0.0-macOS-arm64.dmg`。

文件校验信息统一放在 [2.0.0 发布页](https://github.com/Sunny5250/WithU/releases/tag/v2.0.0)。

## 由你手动批准打开

确认信任该安装包后：

1. 打开 DMG，将 WithU 拖入“应用程序”。
2. 从“应用程序”尝试打开 WithU。若出现“Apple 无法验证”的提示，先关闭该提示。
3. 进入“系统设置 → 隐私与安全性”，在安全性区域找到与 WithU 对应的“仍要打开”。
4. 阅读系统再次显示的提示；决定继续时，按系统要求完成确认。

此操作为该应用建立本机例外，不会让安装包获得 Apple 公证。操作依据见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果找不到按钮，可以先重新尝试打开“应用程序”中的 WithU，再返回设置查看。受公司或学校管理的 Mac 可能不允许建立例外，请联系设备管理员。

如果系统提示应用“已损坏”或“将损坏你的电脑”，请停止安装并反馈具体提示，不要套用本页步骤。
